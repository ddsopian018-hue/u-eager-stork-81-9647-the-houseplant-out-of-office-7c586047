A pure-stdlib Python program that writes the funniest out-of-office auto-reply a houseplant would send: "Out of office: last watered in March. My roots have unionized and gone on strike — please direct all emails to the rain." Unwatered since March, the plant's roots go on strike and its mail gets rerouted to the weather — the plant's own neglected life is the joke, and the punch lands on the last word.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
